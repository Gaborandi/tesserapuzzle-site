The core idea

A region is correct only when its shape and rule both hold.

Every mode asks which cells belong together. The answer changes when the rule becomes numbers, color, or arithmetic.

01Logic

Reverse Sudoku

Draw equal-size connected regions where no number repeats.

02Chroma

Color Mixing

Group primary colors into regions that mix into the target shade.

03Equate

Spatial Arithmetic

Build connected regions whose numbers satisfy an exact equation.
